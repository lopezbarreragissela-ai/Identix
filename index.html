📘 ¿Qué es una identidad trigonométrica?

Una identidad trigonométrica es una igualdad entre razones trigonométricas que es verdadera para todo valor de θ (excepto donde alguna razón no está definida). No es una ecuación que se resuelve para un ángulo específico: es una relación que siempre se cumple.

1️⃣ Identidades pitagóricas

Se basan en el teorema de Pitágoras aplicado al círculo trigonométrico (radio = 1):

  • sen²θ + cos²θ = 1
  • 1 + tan²θ = sec²θ
  • 1 + cot²θ = csc²θ

2️⃣ Identidades recíprocas

Cada razón tiene una "pareja" que es su inverso multiplicativo:

  • csc θ = 1sen θ
  • sec θ = 1cos θ
  • cot θ = 1tan θ

3️⃣ Identidades de cociente

Relacionan tangente y cotangente con seno y coseno:

  • tan θ = sen θcos θ
  • cot θ = cos θsen θ

🧭 ¿Por qué importan?

Permiten simplificar expresiones, comprobar igualdades y resolver ecuaciones trigonométricas sin depender de una calculadora, reconociendo patrones entre las seis razones.

📝 Ejemplos resueltos paso a paso

Ejemplo 1 · Pitagórica — Comprobar para θ = 30°
  1. Datos: sen(30°) = 0.5, cos(30°) = 0.87
  2. Elevamos al cuadrado: sen²(30°) = 0.25, cos²(30°) = 0.7569
  3. Sumamos: 0.25 + 0.7569 = 1.0069 ≈ 1 (la diferencia es por redondeo)
  4. Conclusión: se comprueba sen²θ + cos²θ = 1 ✅
Ejemplo 2 · Pitagórica — Simplificar sec²θ − tan²θ
  1. Partimos de 1 + tan²θ = sec²θ
  2. Despejamos: sec²θ − tan²θ = 1
  3. Conclusión: la expresión se simplifica siempre a 1, sin importar θ
Ejemplo 3 · Recíproca — Hallar csc(θ) si sen(θ) = 0.6
  1. Identidad recíproca: csc θ = 1sen θ
  2. Sustituimos: csc θ = 10.6
  3. Calculamos: csc θ = 1.67
  4. Conclusión: csc(θ) ≈ 1.67
Ejemplo 4 · Recíproca — Completar sec(θ) · cos(θ) = ___
  1. Recordamos: sec θ = 1cos θ
  2. Sustituimos: (1cos θ) · cos θ
  3. Los cos θ se cancelan (si cos θ ≠ 0)
  4. Conclusión: el resultado siempre es 1
Ejemplo 5 · Cociente — Comprobar tan(45°) usando sen y cos
  1. Datos: sen(45°) = 0.71, cos(45°) = 0.71
  2. Identidad: tan θ = sen θcos θ
  3. Sustituimos: tan(45°) = 0.710.71 = 1
  4. Conclusión: tan(45°) = 1 ✅
Ejemplo 6 · Cociente — Simplificar (sen θ / cos θ) · (cos θ / sen θ)
  1. La primera fracción es tan θ, la segunda es cot θ
  2. tan θ · cot θ = tan θ · (1tan θ)
  3. Se cancela tan θ
  4. Conclusión: el resultado siempre es 1 (cuando ambas existen)

🧮 Álgebra con identidades trigonométricas

Aquí usarás las identidades para despejar ecuaciones, factorizar y simplificar expresiones, tal como en álgebra normal, pero con razones trigonométricas. Cada caso trae primero un ejemplo resuelto señalando un error común, y luego ejercicios más largos que combinan varios pasos.

1️⃣ Despeje de ecuaciones trigonométricas

Ejemplo: Resolver 2sen(θ) − 1 = 0

❌ Error común: pasar el −1 "sumando mal" y escribir sen(θ) = 1 − 2 = −1. Esto ocurre por despejar sin respetar el signo original de cada término.

✅ Procedimiento correcto:

  1. 2 sen(θ) − 1 = 0
  2. Sumamos 1 en ambos lados: 2 sen(θ) = 1
  3. Dividimos entre 2: sen(θ) = 12 = 0.5
  4. Buscamos los ángulos entre 0° y 360° donde sen(θ) = 0.5 → θ = 30° y θ = 150°

Ejercicio A: Resuelve para sen(θ) en la ecuación 3·sen(θ) + 2 = 5 − sen(θ). Luego, usando la identidad pitagórica, calcula el valor de cos²(θ) correspondiente. Escribe el resultado final (cos²θ) con 2 decimales.

  1. 3sen(θ) + 2 = 5 − sen(θ)
  2. Agrupamos los términos con sen(θ): 3sen(θ) + sen(θ) = 5 − 2
  3. 4sen(θ) = 3 → sen(θ) = 34 = 0.75
  4. Identidad pitagórica: cos²(θ) = 1 − sen²(θ) = 1 − 0.5625
  5. Resultado: cos²(θ) = 0.4375 ≈ 0.44

Ejercicio B: Resuelve para cos(θ) en la ecuación 2·(cos(θ) + 1) = 3 − cos(θ). Luego, usando la identidad recíproca, calcula sec(θ). Escribe sec(θ) con 2 decimales.

  1. 2(cos(θ) + 1) = 3 − cos(θ)
  2. Distribuimos: 2cos(θ) + 2 = 3 − cos(θ)
  3. Agrupamos: 2cos(θ) + cos(θ) = 3 − 2 → 3cos(θ) = 1
  4. cos(θ) = 13 ≈ 0.33
  5. Identidad recíproca: sec(θ) = 1cos(θ) = 10.33 ≈ 3.00

2️⃣ Factorización de expresiones trigonométricas

Ejemplo: Factorizar sen²(θ) − cos²(θ)

❌ Error común: tratarla como trinomio cuadrado perfecto y escribir (sen(θ) − cos(θ))². Esa fórmula es para a² − 2ab + b², no para una simple diferencia de cuadrados.

✅ Procedimiento correcto:

  1. Reconocemos la forma a² − b², con a = sen(θ), b = cos(θ)
  2. Aplicamos la diferencia de cuadrados: a² − b² = (a − b)(a + b)
  3. Resultado: (sen(θ) − cos(θ))(sen(θ) + cos(θ))

Ejercicio C: Factoriza completamente: sen²(θ)·cos(θ) − cos³(θ). (Pista: primero saca el factor común y luego busca una diferencia de cuadrados dentro del paréntesis).

  1. Sacamos el factor común cos(θ): cos(θ)·(sen²(θ) − cos²(θ))
  2. Dentro del paréntesis hay una diferencia de cuadrados: sen²(θ) − cos²(θ) = (sen(θ) − cos(θ))(sen(θ) + cos(θ))
  3. Resultado final: cos(θ)·(sen(θ) − cos(θ))·(sen(θ) + cos(θ))

Ejercicio D: Factoriza: sec²(θ) − 2·sec(θ)·tan(θ) + tan²(θ). (Pista: identifica el patrón a² − 2ab + b²).

  1. Es un trinomio cuadrado perfecto: a² − 2ab + b²
  2. Con a = sec(θ), b = tan(θ)
  3. Se factoriza como (a − b)²: (sec(θ) − tan(θ))²

3️⃣ Simplificación algebraica (combinando fracciones)

Ejemplo: Simplificar 1sen(θ) + cos(θ)sen(θ)

❌ Error común: sumar numeradores y denominadores por separado, escribiendo el resultado como una fracción con denominador "2sen(θ)". Al tener ya el mismo denominador, no se debe duplicar.

✅ Procedimiento correcto:

  1. Ambas fracciones ya tienen el mismo denominador: sen(θ)
  2. Sumamos solo los numeradores: 1 + cos(θ)
  3. Resultado: 1 + cos(θ)sen(θ)

Ejercicio E: Simplifica combinando en una sola fracción y usando la identidad pitagórica: sen(θ)1 + cos(θ) + 1 + cos(θ)sen(θ)

  1. Común denominador: sen(θ)·(1+cos(θ))
  2. Numerador: sen²(θ) + (1+cos(θ))² = sen²(θ) + 1 + 2cos(θ) + cos²(θ)
  3. Agrupamos sen²(θ)+cos²(θ) = 1 (identidad pitagórica): queda 1 + 1 + 2cos(θ) = 2 + 2cos(θ)
  4. Factorizamos 2 en el numerador: 2(1+cos(θ))
  5. Simplificamos (1+cos(θ)) con el denominador: queda 2sen(θ)

Ejercicio F: Simplifica combinando en una sola fracción: 1 − sen(θ)cos(θ) + cos(θ)1 − sen(θ)

  1. Común denominador: cos(θ)·(1−sen(θ))
  2. Numerador: (1−sen(θ))² + cos²(θ) = 1 − 2sen(θ) + sen²(θ) + cos²(θ)
  3. Agrupamos sen²(θ)+cos²(θ)=1: queda 1 − 2sen(θ) + 1 = 2 − 2sen(θ)
  4. Factorizamos: 2(1−sen(θ))
  5. Simplificamos con el denominador: queda 2cos(θ)

🧩 Casos generales (sin datos específicos)

Aquí no se te da ningún ángulo ni valor numérico. Debes trabajar de forma simbólica, usando solo álgebra e identidades, para que el resultado sea válido para cualquier θ.

Ejemplo: Demuestra que sec²(θ) · cos²(θ) = 1, para cualquier θ (donde cos(θ) ≠ 0).

❌ Error común: reemplazar θ por un ángulo cualquiera, por ejemplo 0°, comprobar que da 1, y concluir "ya quedó demostrado". Eso solo comprueba un caso particular, no prueba que se cumpla siempre.

✅ Procedimiento correcto (símbolico, sin números):

  1. Partimos de la identidad recíproca: sec(θ) = 1cos(θ)
  2. Elevamos al cuadrado: sec²(θ) = 1cos²(θ)
  3. Sustituimos en la expresión: 1cos²(θ) · cos²(θ)
  4. Los cos²(θ) se cancelan (válido para todo θ con cos(θ) ≠ 0)
  5. Resultado: 1, para cualquier θ ✅

Ejercicio G1: Demuestra, sin usar ningún ángulo concreto, que (sen(θ) + cos(θ))² + (sen(θ) − cos(θ))² es una constante para cualquier θ. Escribe esa constante.

  1. Expandimos el primer cuadrado: sen²(θ) + 2sen(θ)cos(θ) + cos²(θ)
  2. Expandimos el segundo: sen²(θ) − 2sen(θ)cos(θ) + cos²(θ)
  3. Sumamos ambos: 2sen²(θ) + 2cos²(θ) (los términos con 2sen(θ)cos(θ) se cancelan)
  4. Factorizamos: 2·(sen²(θ) + cos²(θ))
  5. Por identidad pitagórica, sen²(θ)+cos²(θ)=1 → resultado: 2·1 = 2, para cualquier θ

Ejercicio G2: Simplifica la expresión sen(θ) · cot(θ) hasta dejarla en términos de una sola razón trigonométrica (sin dar ningún valor a θ).

  1. Identidad de cociente: cot(θ) = cos(θ)sen(θ)
  2. Sustituimos: sen(θ) · cos(θ)sen(θ)
  3. El sen(θ) se cancela (para todo θ con sen(θ) ≠ 0)
  4. Resultado: cos(θ), válido para cualquier θ

Ejercicio G3: Demuestra que tan(θ) + cot(θ) es igual a una sola fracción con denominador sen(θ)·cos(θ), para cualquier θ. Escribe el resultado simplificado.

  1. Escribimos cada término como cociente: sen(θ)cos(θ) + cos(θ)sen(θ)
  2. Común denominador: sen(θ)·cos(θ)
  3. Numerador: sen²(θ) + cos²(θ) = 1 (identidad pitagórica), sin importar el valor de θ
  4. Resultado: 1sen(θ)·cos(θ)

Ejercicio G4: Simplifica, sin usar ningún ángulo específico: (1 − sen²(θ))·(1 + tan²(θ)). Escribe el valor constante al que se reduce.

  1. Identidad pitagórica: 1 − sen²(θ) = cos²(θ)
  2. Identidad pitagórica: 1 + tan²(θ) = sec²(θ)
  3. Sustituimos: cos²(θ) · sec²(θ)
  4. Como sec(θ) = 1cos(θ), entonces sec²(θ) = 1cos²(θ)
  5. cos²(θ) · 1cos²(θ) = 1, para cualquier θ donde cos(θ) ≠ 0

💡 Truquitos para no olvidar las identidades

🐘 "SOH-CAH-TOA" extendido: si recuerdas que tan = sen/cos, puedes deducir cot = cos/sen invirtiendo la fracción.
🔄 Los recíprocos van en pares de letras: sen↔csc, cos↔sec, tan↔cot. Nota que sec "suena" a cos y csc "suena" a sen, ¡al revés de lo intuitivo! Apréndelos como pares, no por separado.
📐 La identidad "madre" es sen²θ+cos²θ=1. Las otras dos pitagóricas salen de dividirla: entre cos²θ obtienes 1+tan²θ=sec²θ; entre sen²θ obtienes 1+cot²θ=csc²θ.
🚫 Cuidado con las divisiones entre cero: tan y sec no existen en 90° y 270°; cot y csc no existen en 0° y 180°. Si tu resultado da "indefinido", ¡revisa el ángulo, no tu procedimiento!
✅ Para comprobar una identidad: trabaja un solo lado de la igualdad hasta llegar al otro lado; evita pasar términos "cruzando el igual" como en una ecuación.
🎯 Errores comunes: confundir sen²θ con sen(θ²); olvidar que 1 solo se puede reemplazar por sen²θ+cos²θ cuando conviene a la simplificación.
